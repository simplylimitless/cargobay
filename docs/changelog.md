## [1.0.0] - 2024-02-15

### Added
- Initial stable release
- Backend REST API with chi router
- Proxy handlers: npm, Maven, Docker
- PyPI Proxy (PEP 503)
- NuGet Proxy (V2/V3)
- RBAC with 5 roles (admin, operator, developer, viewer, auditor)
- Storage adapters: S3, GCS, Azure, Local
- Redis caching
- PostgreSQL database with full-text search
- Elasticsearch Integration
- Vulnerability scanner
- CLI Tool
- Prometheus metrics
- Helm Chart
- E2E Tests
- CI/CD Pipeline
- Documentation Site
- Artifact Upload Web UI
- Artifact Browsing Page
- Registry Proxy Status Dashboard
- Vulnerability Scan Results Page
- Audit Log Viewer

## [0.1.0] - 2024-01-01

### Added
- Initial prototype
- Basic REST API
- Docker proxy support
- Local storage adapter
- Basic RBAC
