## What is cargobay?

cargobay is a Universal Binary Repository Manager that supports multiple package formats including Docker/OCI, npm, Maven, PyPI, NuGet, Helm, and more. It acts as a proxy cache for upstream registries while providing additional features like vulnerability scanning, access control, and audit logging.
